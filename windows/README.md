# E阅 Windows

本目录预留给 Windows 桌面端开发。目前尚未创建 Windows 工程、选定桌面框架或生成 Windows 安装包。

开始开发前阅读 [Windows 端开发交接](../release/docs/windows-handoff.md)，其中记录 Android 现有行为、数据兼容要求和待确定的桌面端范围。

Windows 源码、开发和测试放在本目录；未来安装包、便携包及对应源码压缩包统一放在 [`../release/windows/`](../release/windows/)。软件说明和共用文档分别位于 [`release/README.md`](../release/README.md) 与 [`release/docs/`](../release/docs/)。
