# Android 1.11.10：目录分组、EPUB 导入与翻页修复

本轮先生成本地测试包，验证后按作者要求准备 GitHub／网盘发布；实际发布记录见验证文档。不进行手机安装或真机测试。继续使用现有 EPUB／MOBI 兼容引擎，TXT、PDF 链路保持不变。

## 二级目录

原书父子目录仍优先。对于没有父子信息的合集目录，增加通用的罗马数字／数字分册识别，同一系列至少存在两册且册内有编号章节时才分组；同系列的前传、外传等也可归组。“第几幕／回／话”与“第几章”同级。

版权、目录、序言、尾声等仍归入对应分册。版权页之后重复出现、仅罗马数字字形或空白不同的同册标题不会切断该分册；单本书重复的封面标题不算两册。此操作仅改变目录的显示与折叠，不增加或删除实体章节，不重建已导入的缓存，也不移动书签、笔记或字符位置。已有书籍无需重新导入。

验证样本《龙族》的 MOBI 原生目录所有条目均无父子信息，因此以前的卷／章／节规则无法分组；没有按书名进行特殊处理。

## EPUB 导入

完整原文件和所有章节缓存仍在导入时保存。共用的链接 CSS、导入后的样式文件复用，避免为每章重复解析同一套样式、计算摘要和查询样式文件。独立章节的规范文字与缓存写入使用最多四个工作线程，每批最多 32 章，结果保持原阅读顺序。多锚点文档的临时原文缓存最多保留四份。

初次缓存文件改为一次编码写入，既有文件覆盖继续使用原子的写入路径。取消或失败会取消同批任务，并在关闭 ZIP 前等待工作线程结束；正文、注释和图片偏移的提取规则没有更换。

《诡秘之主》样本为 27,663,081 字节，含 1415 个正文文件。相同电脑、同一单独测试、新建测试进程的对照结果：

| 阶段 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 原生目录 | 237 ms | 256 ms |
| 完整解析（含目录） | 846 ms | 790 ms |
| 规范文字及全部缓存 | 3070 ms | 1789 ms |
| 合计 | 3916 ms | 2579 ms |

目录本身约四分之一秒，主要等待来自规范文字和缓存生成；这些数据不能换算为手机端的实际耗时。全量回归中预热后的合计约 1781 ms。逐章核对全部 1415 章的规范文字、图片、注释和 CSS，取消导入也有回归验证。

## 覆盖／仿真翻页

EPUB／MOBI 改用 Chromium 的同文档 View Transition 截图和合成动画，不再经 JavaScript 桥接调用 Android 的软件截图参与正常翻页。该 API 由浏览器捕获更新前后的画面，并在内部交接：[Chrome 官方说明](https://developer.chrome.com/docs/web-platform/view-transitions/same-document)。

覆盖模式保留前后页层叠移动；仿真模式使用纸页旋转与明暗过渡。快翻、反向翻页、切换模式会撤销旧动画，旧回调不能覆盖新的目标。过渡层使用当前纸色或自定义图片背景，避免透明截图导致两页文字叠在一起。结束后释放所有动画效果，直接保留目标页。

不支持该 API 的旧 WebView 回退为浏览器内部的滑动动画，仍可翻页，但不提供同样的覆盖／仿真视觉效果。墨水屏和上下模式保持直接翻页。手机 WebView／GPU 的实际观感尚未验收。

## 数据与 Windows 交接

书库版本 13、WebDAV 协议版本 1、EPUB 内容版本 10、MOBI 内容版本 8 均未变。规范文字、源 HTML/CSS、章节边界和源注释的解析摘要在 15 份本地／公开样本上前后一致。没有改写用户原件或调整原字符偏移。

Windows 工程没有修改；新目录分组是 Android 的显示推断，新翻页方式及临时背景资源端点也不进入书库／云端协议。详细检查结果见 [验证记录](verification.md)。
