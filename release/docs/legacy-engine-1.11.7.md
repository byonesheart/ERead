# Android 1.11.7：按需初始化本地试版

本轮按作者要求只生成本地测试包，不上传 GitHub、网盘或线上更新清单，不进行手机安装测试。运行结果见 [验证记录](verification.md)。

## 导入和打开

新 EPUB 先读取包信息、阅读顺序及目录，再准备封面和最初的可读正文。其余章节保存轻量引用，文字、原书展示缓存和插图在访问时生成。多个目录节点共用同一 HTML 时，仍需读取该资源检查实际分界，避免失效或注释锚点造成重复章节。纯图片书仍须检查正文后归入漫画。

新 MOBI 延后提取各章规范文字、插图及样式投影；当前 MOBI 解码器的一次解压、HTML 目录和注释目标识别仍在导入阶段执行，没有将所有 MOBI 改成仅读文件头。自定义目录规则继续使用原有解析流程。这些限制不能描述成所有格式均可秒开。

两种格式完整原文件都保留在书籍私有目录。阅读不依赖临时来源授权继续存在。打开 EPUB／MOBI 时只读取轻量章节长度索引，当前章节及相邻章节继续优先准备，沿用原书 HTML/CSS 的 WebView 显示和相邻页面预加载。

## 阅读期间建立索引

页面就绪且没有手动移动约 1.5 秒后，以较低线程优先级逐章准备剩余缓存；每章之间留出调度间隔。移动页面、切章、进入后台或离开阅读时取消当前后台任务，已提交的章节保存在磁盘上，之后继续处理。

未完成章节的全书进度权重先使用估算值，逐章准备后替换为实际 UTF-16 长度；当前章页码仍由当前页面计算，不预先汇总全书页数。估算更新不改变当前章节、字符锚点或已有标注。

正文缓存与章索引分别提交。同一章节的访问合并处理；已经保存的文本不因后台初始化重新覆盖。已经完成的章节在再次打开时复用。图片按需写入，整书只保留轻量引用，正文和 DOM 的阅读窗口上限沿用 1.11.6。

全文搜索、总字数、批量语音和保存／备份按实际需要读取对应章节。显式保存原文件及完整备份仍可遍历全书，不将未初始化章节误当成空正文。初始化产生的派生缓存不把未编辑的书籍标记为新的云端内容。

## 数据与 Windows 交接

只对新导入书籍采用上述引用；既有书库不强制重建、重导入或重新分章。新 EPUB 内容版本为 10，MOBI 为 8；本地书库版本 13、WebDAV 协议版本 1 保持不变。章节 ID、阅读位置和标注继续使用既有 UTF-16 语义。

Android 私有缓存新增每章 `.source.json.deferred.json`、`.source.json.indexed.json` 与书籍目录 `ebook-lengths.json`。它们用于延迟准备和恢复进度，不是新的云协议。WebDAV 上传先物化完整章节，移除本地懒加载引用，再使用原有云格式上传；Windows 无需读取这些 Android 缓存文件。本轮没有修改 Windows 工程。

桌面测试不能替代 Android WebView 的实际触控、首次字体加载及帧率验收。安装本地包后仍需检查作者设备的开书与切章体验。
