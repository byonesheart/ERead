# 阅读排版与书架调整（1.11.14）

本轮修正最初使用 1.11.13／versionCode 56 的独立文件名测试包，现已并入 **1.11.14** 发布；正式 Release 构建使用 **versionCode 58**，可覆盖此前 versionCode 57 的测试构建。构建及发布验证见文末的验证记录。

## 字体与简繁切换

EPUB／MOBI 的字体先通过 FontFace 加载，成功后一起提交字体、字号校准和页面样式。等待期间保留原字体，连续切换时放弃过期结果。背景调整复用已加载字体，字体资源按请求 URL 对应具体选择，避免较晚到达的旧请求读到新字体。单个页面最多保留三份字体加载结果。

简繁切换直接更新已有正文节点和显示偏移映射，不因简繁选项重建章节 WebView 或连贯滚动的 iframe。词典准备期间保留上一种显示；书签、笔记、搜索和朗读继续使用原文 UTF-16 偏移。

## 竖排文字

入口：**阅读 → 界面 → 文字与排版 → 排版 → 竖排**。汉字自上而下、列从右向左，采用 [CSS Writing Modes](https://www.w3.org/TR/css-writing-modes-3/) 的 `vertical-rl`。滚动、左右操作翻页和上下操作翻页均可使用；当前竖排为单页，横排双页规则不变。竖排笔记／划线显示在文字列旁，标注仍定位原文。

EPUB／MOBI 保留源文档、图片和注释。TXT 仅在选中竖排时把当前章节安全转义为 HTML，沿用同一正文映射和相邻窗口；不转换整本书或写回文件。横排 TXT 和 PDF 沿用原链路。

新增可选 `ReaderSettings.verticalText` 和阅读配置 `ReaderAppearance.verticalText`，旧数据缺省 `false`。小说、漫画设置仍独立；恢复默认重置当前模式。书库版本 13、WebDAV 协议版本 1 不变。

## 设置与书架

- 使用原书 CSS 移到“文字与排版”，只对 EPUB／MOBI 显示。
- 连贯滚动位于“翻页方式 → 滚动”的子设置，切到翻页／上下时隐藏，不清除原选择。
- 三列书架使用统一封面高度和两行书名区域；书名不足两行也占相同空间，作者、章节、百分比和进度条对齐。
- 书籍更多面板及书籍信息显示可复制的位置；外部引用显示授权文档 URI，应用内副本显示实际保存路径，未下载书籍注明尚无本机文件。
- 整书／选章生成语音缓存前检查 AI 配置，未配置时显示提示并可进入朗读设置，不先申请通知权限或提交后台任务。

构建、浏览器与 Android 回归结果见 [构建与验证记录](verification.md)。未进行真机安装或运行验收。
