# 1.11.13 界面与阅读记录（本地测试）

本轮只生成本地 Android 测试包，未发布到 GitHub 或网盘。经典、像素、星彩沿用各自配色与图标，共用书架和设置布局。

## 书架与最近阅读

- 未下载书籍保留封面和云端按钮，移除“待下载”文字。点击封面、书名或列表行会提示书籍还未下载，不直接进入阅读器；点击云端下载按钮仍执行原有下载流程。
- 三列书架把百分比单独放在章节进度下方，保持左侧对齐；列表仍使用紧凑进度条。
- 星彩也显示“最近阅读”，三种主题均可在外部设置中开关，默认开启。该开关只控制首页最近阅读区块，不清除历史、进度或继续阅读卡片。
- 长按管理、重命名、分组、云端操作及批量选择继续保留。

## 设置与阅读界面

外部设置统一为星彩风格的三组卡片：主题和夜间模式；最近阅读、墨水屏、横屏双页和朗读引擎；WebDAV、缓存、反馈、支持与关于。三种主题共用排布与图标占位，颜色、像素图形与边角随主题变化。

阅读内“界面”参考用户提供的 `ebook-2.0.5-build.55.zip`，按配置、翻页方式、文字与排版、纸张与亮度、页边距分组。配置采用紧凑横条，当前配置自动移到可见位置，新建按钮固定在右侧；背景小样继续来自原配置背景，长按管理和删除确认、配置自动保存保留。字号、行距、段距、字距和四边边距保留拖动预览、松手提交及加减微调；字体和图片导入、简繁转换，以及覆盖／滑动／仿真效果沿用原功能。漫画原页不显示正文排版控件。

“关于 → 贡献者”展示 7Mrlan 的头像与 GitHub 链接，并注明星彩界面及软件测试、Bug 反馈方面的贡献。头像来自用户提供的图片。

## 数据与兼容

`library.json` 新增可选布尔字段 `showRecentReading`，缺省为 `true`，由外部共用设置保存；未增加到小说或漫画阅读配置。旧书库无须迁移。关闭开关时，书籍的 `lastReadAt`、阅读位置及统计保持不变。

书库版本仍为 13，WebDAV 协议仍为 1。本轮未更换阅读引擎、导入解析器、正文缓存、朗读或云端实现。Windows 端读取共用书库时可忽略该可选外观字段；若支持最近阅读设置，应采用相同缺省值。未修改 Windows 工程。

构建、桌面测试与安装包校验见 [构建与验证记录](verification.md)，不代表手机端验收。
