# Android 1.11.5 连贯阅读与导入优化

本轮继续使用原书 HTML/CSS 的兼容 WebView 引擎。仅生成本地安装包，不上传 GitHub、网盘或更新清单，按作者要求没有手机测试。构建与测试结果见 [验证记录](verification.md)。

## 阅读行为

- EPUB／MOBI 默认开启“连贯滚动”，在书内“设置”中可以关闭，恢复原逐章滚动。TXT、PDF、漫画及翻页／上下模式继续使用原链路。
- 同一滚动页面衔接章节，每章使用独立的本地 HTML/CSS 上下文，避免同名样式、元素 ID 或字体规则相互覆盖。全书只保留标题、长度与高度占位，重型 DOM／正文资源只保留当前章及相邻两章。替换上方章节占位时补偿高度变化，保留可见文字位置。
- 章节由原生组件按需供给，不加载远程网页。只允许当前会话登记的本地子文档，书内脚本、嵌套 iframe、文件路径及外部网络限制保持不变。
- 默认“滑动”翻页改为浏览器对现有页面执行合成动画，不等待 Android 截图、桥接往返与绘制回调。覆盖／仿真继续保留原生动画；等待新画面时允许 WebView 提交绘制，同时用快照遮住尚未就绪的画面。
- 书签、笔记、编辑、搜索及朗读继续采用原章节号和 UTF-16 字符位置；跨章事件附带实际章节号，选区与注释坐标换算到阅读窗口。

## 导入与外部打开

- 导入新书时，未提交到书架的章节正文、样式和索引使用缓冲写入，减少逐文件强制落盘。已有文件的覆盖与书架提交仍保留原子写入。
- EPUB 插图提取复用一次 ZIP 打开和条目索引，避免每张图片重复打开、枚举归档；完整 EPUB 原文件仍保存。
- 从外部打开单本书时直接进入打开流程，准备好后进入阅读；不再等待导入阶段的 TXT 预分页。已保存本地副本且原文件名与原始大小完全一致时，直接打开已有记录，不重复导入、覆盖笔记或进度。
- 返回可将尚未完成的外部打开留在后台导入，完成后不再强制跳入阅读。来源不明、同名无法确认的情况继续使用现有冲突确认。

## Windows 与书库兼容

本地书库版本 13、WebDAV 协议版本 1 不变。不改已有章节编号、书籍 ID、云端身份或原始文件。新增可选偏好 `ReaderSettings.continuousEbookScroll`，缺省为 `true`，只影响 Android 的 EPUB／MOBI 滚动显示；Windows 无需同步改变渲染方式，往返存储时应保留不识别的设置。

Readium 已在 1.11.4 移除。历史资源索引及 Locator 附加文件的保留规则继续见 [兼容引擎说明](legacy-engine-1.11.4.md)。没有修改 `windows/` 的实现或构建配置。

## 验证边界

桌面 Chromium 覆盖真实触摸／滚轮跨章、独立样式、前后定位、窗口上限、返回缓存、上方章节重排补偿、笔记／选区坐标及连续翻页动画。Robolectric 运行实际 ReaderScreen，覆盖默认连贯组件、可信子页面供给、跨章进度以及旧逐章导航。实际 MOBI 和公开 EPUB 样本继续通过现有导入、资源与位置回归。

首次导入仍需读取并检查原文件，应用进程重启仍需创建 WebView、排版当前章；极快跳到未准备的章节仍可能短暂等待。桌面验证不能替代 Android WebView 的实际帧率、触控与系统兼容验收。
