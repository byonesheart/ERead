# 1.9.9 阅读与备份性能调整

本次针对章节内存、阅读进度保存、云端记录更新和语音缓存刷新进行调整。

| 场景 | 调整后的行为 |
| --- | --- |
| 连续跨章阅读 | 正文、源样式、滚动块和分页边界只保留当前及相邻章节；远章仅保留章节信息、长度和滚动项数量。 |
| 返回已释放章节 | 按需重新读取该章，复用落盘的章节准备及分页缓存；保留滚动块与原文位置，避免恢复到章首。 |
| 保存阅读位置 | 位置、进度和阅读时长写入独立的 `reading_positions.json`；书架结构或标注变化时才重写书架文件。 |
| 云端待更新标识 | 按书复用结构指纹；某本书的位置变化不会重新序列化其他书的章节，也不会重新查询其文件属性。 |
| 从书中任意位置朗读 | 先准备当前章，不读取之前的章节。系统朗读按章接续；AI 音频最多预取两个后续分段，先播放已就绪内容。 |
| 云端更新阅读记录 | 已确认未变的私有本地文件复用摘要；正文与记录的版本分开判断，原云端分块及归档协议保持兼容。 |
| 目录语音标识 | 读取按章完成索引与缓存文件元数据，不再读取整本书正文或重新规划全书语音。 |

位置文件带书架结构版本和正文版本。导入、编辑、删除及云端还原产生新结构后，旧位置文件不会覆盖新数据或恢复已删除书籍。

资源摘要只在可获得可靠文件身份时复用，同时比较设备、inode、大小、纳秒修改时间和变更时间，并检查读取前后版本。公共目录、文档提供者及无法可靠验证的资源仍完整校验；因此不承诺所有外部文件都能跳过读取。缓存文件可随书籍删除，缺失后自动重新生成。

语音旧分段缓存继续复用。缺少可信完成索引的旧缓存，会在该章完成播放或生成后重新建立完成标识。角色提示默认仍关闭；开启后，连续播放延续角色上下文。直接跳到尚无角色检查点的远章时，以当前章上下文判断，不再为了推导前文角色而扫描之前所有章节。

验证结果见 [构建与验证记录](verification.md)。桌面回归用于核对读取范围、数据一致性及交互行为，不等同于手机内存峰值、帧率或网络速度测量。
