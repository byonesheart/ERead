# Android 1.11.9：导入扫描与阅读交互本地测试

本轮仅生成本地测试包，不上传 GitHub、网盘或线上更新清单，不安装到手机。验证结果见 [验证记录](verification.md)。

## 导入优化

保留原书目录优先、完整原文件和导入时完成所有章节缓存的要求，继续使用兼容引擎。没有恢复阅读期延迟生成新书缓存。

HTML 文档在导入期间共享一次标签扫描结果，用于隐藏内容、目录锚点、注释范围、CSS 和链接识别。MOBI 的二进制目录提前读取；处理正文时复用扫描结果，使用原始字符区间分配各章注释引用，不再为分配注释目标而重新扫描每一章。EPUB 的锚点通过一次 ID／name 索引查找，同一资源的注释引用按章节区间复用。规范文字提取也复用注释和隐藏内容的扫描；普通章节不再无条件复制一份无变化的 HTML。

这些扫描只在当前解析调用中持有，不作为新的全书阅读内存缓存。MOBI 仍需首次解压；保存完整缓存仍有文件写入及文字提取成本。

导入进度区分原书目录、正文解压／读取、图片资源、正文与注释处理、章节缓存。不会将正文扫描一直标成“读取目录”。

## 进度条目标预览

拖动进度条显示目标章节、百分比和该章页码，松手才提交跳转。未完成页码准备时明确显示“计算中”。TXT 复用当前章节的分页算法及磁盘缓存；图片／漫画直接按实际页面映射。

EPUB／MOBI 为当前指向的章节使用一个独立、不可见的预览 WebView，按实际原书排版计算页码。切换目标章节后取消旧任务并释放旧预览；同一章节内移动目标复用该页面。预览与可见页面的控制器、位置回报分开，不改变阅读进度和返回位置，也不汇总全书页数。快速拖动先更新章节提示，指向同一章节约 120ms 后才准备其页面。

该预览最多额外持有一个章节 DOM，仅在拖动期间存在；原阅读会话仍保留当前及相邻窗口。

## 覆盖与仿真翻页

EPUB／MOBI 横向覆盖、仿真翻页先取得旧画面，再等待 Chromium 提交目标画面，之后用两张视口截图完成过渡。动画期间不混用可能落后的实时 WebView 帧。结束时先保持目标截图，等待目标 WebView 画面提交后再交还实时绘制，避免旧页面再次露出。

两张截图在完成、取消、尺寸变化及阅读会话释放时回收，迟到的提交回调不能覆盖新的翻页。滑动翻页、上下模式和墨水屏分支保持原有行为。实际手机 WebView 的视觉流畅度仍需设备体验确认。

## 数据与 Windows 交接

书库版本 13、WebDAV 协议版本 1、EPUB 内容版本 10、MOBI 内容版本 8 保持不变。未重建旧目录、改写用户原件或改变 UTF-16 字符定位。Windows 工程没有修改，也不需要读取 Android 的临时扫描索引、预览 WebView 或截图。
