# 星彩主题（Android 1.11.11 本地测试）

入口：**设置 → 主题 → 星彩**。经典仍为默认主题，像素主题保留，可以随时切换。此次仅生成本地安装包，不上传 GitHub、网盘或修改线上更新清单。

主题首次加入 1.11.11；下述共用书架及长按面板现已另行打包为 **1.11.12**，避免与此前同名本地包混淆。

**1.11.13** 进一步统一三种主题的设置页，阅读内界面也采用参考源码的分组和紧凑控件，并给星彩补充默认开启的最近阅读。最新范围与可选持久化字段见 [1.11.13 界面说明](interface-1.11.13.md)。

## 界面来源与范围

参考用户提供的 `ebook-2.0.5-build.55.zip` 中当前启用的蓝色界面，移植浅蓝／深蓝配色、紧凑排印、彩色导航、星月／书签／导入图标、横向继续阅读卡片、三列书架和分组设置卡片。参考源码里较早的其他皮肤截图不是本次采用的界面。

新主题沿用现有封面加载、书籍更多菜单、云端入口和导入面板。设置保留支持作者、更新提示等原有入口，未采用参考界面中的演示提示或模拟操作。

按后续要求，经典、像素和星彩共用三列封面及紧凑列表的书架布局，各自保留配色、图标与边角。长按封面、书名或列表行，以及点击“…”均打开参考源码风格的底部操作面板；重命名移至面板入口。书籍信息、分组、AI 语音、角色、云端和移除操作沿用原有能力与确认流程，漫画及待下载书籍继续按实际能力显示选项。批量选择时长按不打开面板。

字体和圆角应用于软件界面；阅读内的字体、字号、间距、阅读模式和配置仍由现有小说／漫画设置管理。深色跟随原有浅色／深色／系统选项；墨水屏使用现有高对比配色，新主题图标切换为单色。

## 数据与功能边界

只新增全局主题枚举 `XINGCAI`，使用现有 `appTheme` 字段保存。书库版本 13 和 WebDAV 协议版本 1 不变；旧版本不识别该主题时仍会回退经典外观。未更换阅读引擎、EPUB／MOBI 解析器、缓存、书签／笔记、TTS、WebDAV、更新服务器或账号逻辑；未引入参考项目的引擎模块、依赖、启动图标、作者或仓库地址。

参考源码保存在本机忽略的 `app/.tools/xingcai/reference/`，没有加入应用源码目录。主题图形和布局置于 `ui/Xingcai*.kt`，共用书架操作面板置于 `ui/ShelfBookActions.kt`。

## 验证

验证主题选择和持久化、切回经典、小说／漫画设置不被覆盖、实际阅读页打开、书架和 WebDAV 设置导航、导入入口、更新红点及墨水屏单色图标。界面截图来自桌面 Robolectric 原生绘制，不等于手机端视觉或性能验收。构建及验证记录见 [verification.md](verification.md)。
