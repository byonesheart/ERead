# Windows 增量交接：Android 1.10.2

更新日期：2026-10-22。本次 Android 基线为 **1.10.2 / versionCode 41**，源码标签 `v1.10.2`，发布入口为 [1.10.2 Release](https://github.com/byonesheart/ERead/releases/tag/v1.10.2)。本文接续 [完整交接](windows-handoff.md) 和 [1.10.1 增量交接](windows-handoff-1.10.1.md)，具体 Android 构建结果见 [验证记录](verification.md)；本文不声明 Windows 已完成适配。

## 字体视觉尺寸与字距

Android 的内置宋体／黑体继续使用原始思源字体资源，本次没有改字体文件。相同字号并不代表不同字体的字形墨迹与字符步进相同，因此新增 `ui/ReaderFonts.kt` 的 `readerFontCalibration`：

- 以当前系统字体为参照，测量“国田中日月山水书读”九个汉字的实际墨迹长边均值及平均字符步进；按粗细和区域设置取得对应度量。
- 内置字体按墨迹比例做均匀缩放，比例限制为 0.8–1.15；再增加字距补偿，使缩放后的字符步进尽量贴近系统参照，不横向拉伸字形。
- `ui/ReaderLayoutPreparation.kt` 的显示与测量共用校正结果：实际字号为用户字号乘比例，实际字距为用户字距加用户字号乘补偿 em。系统字体和用户导入字体保留自身尺寸，不套用内置字体校正。这是视觉近似，不能承诺所有字形逐个等大。
- 新建或缺失字距设置的默认值改为 **0.5 sp**；已明确保存的值（包括 0）保持原值，不批量重写小说、漫画或已保存配置。
- `ui/ReaderPageCache.kt` 的分页算法版本升为 **11**，旧页表失效后仍仅按需计算当前章；不恢复全书统计。

字体来源及排版说明见 [fonts.md](fonts.md)。Windows 应按自身文本引擎和 DPI 测量墨迹、字符步进，并保证绘制与测量使用同一校正结果，不能复制 Android 校正数值或复用 Android 页表。

## 像素主题实际影响图标

`ui/AppIcon.kt` 为主题图标统一入口：经典主题使用原矢量，像素主题将实际字形绘到 16×16 网格后以最近邻放大。保留原有点击区域、说明文本及状态着色，包含深色模式、朗读红色和禁用态。Windows 需将自己的功能图标接到主题实现，不能只改变按钮边框和颜色；阅读配置与软件主题仍独立。

## 原书注释惰性补识别

- TXT 的 `data/TxtSourceFootnotes.kt` 识别正文 `[n]` 与后续章末 `[n] 释文`，按连续定义块绑定；既支持每章重置编号，也支持同章附录重新编号。定义本身不变成引用，重复且不能明确绑定的定义保持普通文本。
- `data/SourceHtmlFootnotes.kt` 改进 Calibre 的正文引用／注释回链识别：相同 `[n]` 标签和通用 `filepos` 锚点不能单独作为区分依据，需要结合目标、块位置及回链关系。正文小标显示注释内容，注释开头的回链不误当成另一条注释。
- 旧 manifest 缺少 `noteTargets` 时，只在章内有同号数字回链和目标关系证据时恢复带文件名的 EPUB 链接或 MOBI 绝对 `filepos`，不猜测其他文档的同名锚点。实际样本两种格式全书均恢复 1485 条，不能因此宣称任意旧书的跨章目标都可恢复。
- `data/LazyChapterContent.kt` 对 TXT 在加载当前规范正文时附加注释元数据；EPUB／MOBI 的 prepared 投影使用 **`sourceFootnotesVersion=2`**（CSS 投影仍为 1），按需重建旧注释投影。无需重新导入整书，不提前扫描全书。
- 注释补识别保持原规范正文、已保存编辑及 UTF-16 偏移，不拿原文件覆盖现有正文。原书注释仍与用户笔记分开，清理笔记不能删除原书注释。

本次 **`library.json` 仍为 version 13，WebDAV catalog／manifest／归档 metadata 仍为 version 1**；分页算法和 prepared 投影版本是本机缓存失效标记，不是新的跨端数据协议。
