# Android 1.11.6 跳转、相邻章节预加载与 EPUB 打开优化

本轮开发验证仅在电脑端进行，没有手机安装测试。作者随后要求上传 GitHub 并分享网盘，发布状态见 [验证记录](verification.md)，下载入口见 [软件介绍](../README.md)。

## 阅读位置与预加载

进度条快速连续跳转时，返回位置、章节名称和百分比直接从本次跳转前的实际状态计算，避免复用旧界面回调捕获的派生值。跨章跳转尚未完成时，旧章节迟到的位置回报不能覆盖新目标。关闭工具栏后，返回按钮仍按原有规则清除。

EPUB／MOBI 翻页和上下阅读模式在当前页就绪后，以实际阅读区域尺寸提前创建、排版相邻章节的 WebView，包括字体、插图及原书样式。前往相邻章节时接管已准备的页面。缓存仍以当前章为中心，只持有当前和相邻两章；预加载不能移动保留窗口或驱逐正在准备的另一个邻章。页面交接使用持有者校验，旧预加载组件的释放回调不能暂停或清空刚被阅读界面接管的页面。

尚未完成预加载就立即切章、跳到远处章节、首次读取大型章节时，仍可能需要准备时间。预加载减少首次切章的前台等待，不代表可以跳过所有布局工作，也不代表已验收手机帧率。

## 参考 liseur 的导入思路

参考仓库 [chmouel/liseur](https://github.com/chmouel/liseur)，本轮检查固定于提交 `7feab3b0feb1e62170d89736afe382560c7f37ea`。其 [LocalLibraryRepository](https://github.com/chmouel/liseur/blob/7feab3b0feb1e62170d89736afe382560c7f37ea/app/src/main/kotlin/com/chmouel/liseur/data/library/LocalLibraryRepository.kt) 的 `indexBook` 通过 Readium 打开资源后，主要保存标题、作者、封面、系列及文件引用；没有在导入事务中逐章生成完整的纯文字、样式和笔记字符索引。它还优先识别已有文件，并在来源授权足够持久时直接使用来源引用。

本轮借鉴减少重复准备的思路，没有引入或复制其 Readium 阅读链路：

- 重复选择单本书导入时，先按用户既定的“原始文件名和原始大小均完全一致”规则查询已有记录，匹配后复用书籍，避免重新复制和解析。无法确认的同名冲突仍使用原有流程。
- 新导入 EPUB 保存可直接阅读的章节结构及原归档路径。首次打开只读取所需章节的展示缓存，不再重新解析、切分整本 EPUB 或生成全书展示 HTML；相对 CSS／图片／字体路径、原书 head 和嵌套元素保留。
- 同一 EPUB 资源拆成多章时复用一次原始资源读取；通常每章一个资源时直接使用首次解析得到的原始 HTML。

E阅仍保留完整 EPUB 原文件及用于字数、全文搜索、旧笔记与朗读位置的规范文字索引。首次导入仍需要读取原文件和建立索引，MOBI 仍需完成首次解压；不能据此承诺所有大小和格式都“秒导入秒开”。既有 EPUB 不强制重导入或改写章节号。

## 数据兼容

新 EPUB 导入内容版本为 9，内部章节源文件版本仍为 3，新增可选 `archivePath`，用于恢复相对资源地址。历史 EPUB 6／8、MOBI 及云端还原的已物化章节保留兼容路径。本地书库版本 13、WebDAV 协议版本 1 不变；正文、书签、批注和朗读继续采用原章节及 UTF-16 字符位置。没有改动 Windows 实现。

源代码审查及桌面自动化不能替代 Android WebView 的实际触控和绘制验证；安装后仍需在作者设备上确认实际体验。
