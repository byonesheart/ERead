# Android 1.11.8：内置目录优先与完整导入缓存

本轮按作者要求恢复导入时完整缓存，只生成本地测试包，不上传 GitHub、网盘或线上更新清单，不进行手机安装测试。验证结果见 [验证记录](verification.md)。

## 目录规则

- EPUB 优先使用 EPUB 3 的导航目录；没有可用导航目录时再使用 NCX。阅读顺序仍依据 spine，同一资源内按目录锚点分节，保留原书标题、分卷关系、图片、字体和注释，不用正文正则覆盖原目录。
- MOBI 优先使用原文件的二进制目录及可用的正文链接目录。已经有内置目录时不因全局自定义正则重新合并、拆分章节；没有内置目录时保留原有标题／分页标记／正则回退。
- 现有书库不自动重新分章，避免移动已有阅读位置和批注。新优先级用于新导入；没有文本编辑的 MOBI 在明确重建目录时同样尊重内置目录。

旧 EPUB 若曾因合并 NAV／NCX 保存了额外锚点，读取原书和写回编辑时会核对已保存的章节数量，必要时使用旧合并目录；1.11.7 的延迟章节引用同样按原合并规则恢复。不会为采用新目录而直接覆盖旧章节边界。

## 缓存与打开

恢复 1.11.6 的完整导入缓存流程：导入完成前写入所有章节的规范正文、原 HTML/CSS 展示资料、注释及引用插图。原文件继续完整保留。恢复此行为会增加导入阶段的等待，但不再把剩余章节缓存工作留到日常阅读中执行。

保留开书复用缓存、原书结构 WebView 展示和相邻章节预加载。新的完整缓存书籍不再启动 1.11.7 的阅读期全文初始化任务；安装过 1.11.7 而留下的未完成按需书籍继续可读取、续建缓存。样式投影与实际 WebView 布局沿用 1.11.6 的按章处理，不预先汇总全书页数。

## 数据与交接

本地书库版本 13、WebDAV 协议版本 1、EPUB 内容版本 10、MOBI 内容版本 8 不变。恢复完整缓存并不改变 UTF-16 字符偏移及注释含义。Windows 工程未修改，也不要求读取 Android 的私有缓存文件；云端仍使用原有完整物化格式。

TXT、PDF 链路保持原样。电脑测试不能替代手机的触控、WebView 排版和实际流畅度验收。
