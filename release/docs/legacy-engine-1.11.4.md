# Android 1.11.4 兼容阅读引擎

EPUB／MOBI 统一回到原书 HTML/CSS 的兼容引擎，使用系统 WebView 显示。Readium Shared／Streamer／Navigator、Fragment 宿主及切换设置已经移除；TXT、PDF 和漫画链路保留。Android 工具链保持现有版本，未修改 Windows 实现。

## 本轮改动

- 由阅读主界面持有有上限的页面会话。保留当前和相邻的已访问章节；来回切章、退出阅读后在同次应用运行中重开，可以复用已完成排版的页面。切换书籍、内容版本变化或离开保留窗口时销毁过期页面。
- 章节文字尚在读取时，保留原书阅读组件；不再因外层加载分支而反复销毁它。
- 缓存页面恢复时更新设置、笔记和高亮，按实际目标位置决定保留视口或跳转，不重新加载整份文档。
- 恢复阅读位置放到首次显示之前。可信 HTML 启动阶段隐藏正文但保留布局，完成定位并确认 WebView 绘制后显示，避免先闪出章首。已应用的启动跳转不会重复执行。
- 翻页等待 Chromium 新页面绘制提交后启动动画，新旧页面分区绘制，避免透明背景上的正文叠加。
- MOBI 优先使用导入时保存的章节 DOM、CSS 和插图，不重复解压整本原书。旧导入缺少这些文件时保留原有解析回退与明确错误。

## 书库与 Windows 交接

不重导入、不重编号已有书籍或章节，不批量改写笔记和进度。`library.json` 与 WebDAV 协议版本未改变，阅读位置仍以章节和 UTF-16 字符偏移保存。

历史 `readium-publication.json`（version 1）继续作为普通资源索引读取和云端往返保存，保留其原有 spine 章节划分、ID 和文本索引；该文件名不表示仍运行 Readium。`LegacyEpubIndex` 只使用本地 ZIP 与既有 HTML 处理器。旧 Locator 附加文件保留到用户清理，但不再生成、读取为新位置或参与导航。

旧 `epubEngine` 设置忽略。新导入 EPUB 使用原兼容导入器；完整原文件仍保存为私有 `source.epub`，不能用投影文本重建原书。Windows 应继续保留不使用的历史资源索引。

## 验证与边界

组件测试覆盖页面会话复用、缓存窗口上限、过期回调隔离、启动位置仅消费一次、前后台超时控制、旧 spine 索引及 EPUB 2／3／UTF-16 资源读取。公开样本包括图文混排、内部链接、竖排、SVG spine、固定版式漫画及混淆字体；通过导入和抽取章节读取不代表全部视觉排版功能已验收。

实际《龙族》153 章 MOBI 验证导入后从缓存读取首章、最长章、中段和末章，并确认打开过程无需原文件再次解压；用户原文件保持不变。Chromium 测试覆盖三个阅读模式下的首报、定位、缓存恢复、原书样式、注释与章末边距。

页面会话在应用进程／Activity 存活期间复用；进程重启后仍需创建 WebView 并排版当前章，不能承诺完全零加载。没有复用 Readium 的 DRM、字体解混淆或 EPUB 脚本扩展；不支持的嵌入字体依赖系统回退。安全策略继续禁用书内脚本与远程资源。

遵照作者要求，本轮仅电脑端测试，没有安装到手机、没有验收 Android WebView 的真实翻页帧率，也未上传 GitHub 或网盘。最终构建及测试数量见 [验证记录](verification.md)。
