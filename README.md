# E阅

<img src="release/assets/E阅图标.png" width="88" alt="E阅图标" />

一款本地小说与漫画阅读器，现有 Android 版支持看书、听书、阅读标注和个人 WebDAV 备份。

[下载与软件介绍](release/README.md) · [更新记录](release/CHANGELOG.md) · [GitHub Releases](https://github.com/byonesheart/ERead/releases)

## 项目目录

| 目录 | 内容 |
| --- | --- |
| [app/](app/) | Android 工程，包含 Gradle 构建配置、脚本和 `app/app/` 应用模块。 |
| [windows/](windows/) | Windows 端开发目录，技术方案与首版范围尚待确定。 |
| [release/](release/) | 两端共用的安装包、说明文档、更新清单、图标和宣传素材。 |

Windows 开发请先阅读 [Windows 端开发交接](release/docs/windows-handoff.md)；Android 构建与发布见 [GitHub 发布说明](release/docs/github-publish.md)。仓库许可证见 [LICENSE](LICENSE)。
