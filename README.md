# E阅 · Android 本地阅读器

<img src="E阅图标.png" width="96" alt="E阅图标" />

Kotlin + Jetpack Compose 原生 Android 应用，最低支持 Android 8.0（API 26）。无需独立 E阅账号，默认在设备本地保存文件、书架、阅读位置和标注；可选配置 WebDAV 网盘进行备份和手动还原，兼容原坚果云配置。

## 软件特点

- 小说、漫画双模式，支持 EPUB、TXT、未加密 MOBI、PDF、图片及多层漫画文件夹。
- 滚动、左右与上下翻页，提供覆盖、滑动、仿真效果，以及可选的墨水屏和平板横屏双页阅读。
- 自定义字体、背景、段距，独立保存小说和漫画偏好；支持书签、笔记、标记、划线及全文搜索替换。
- 系统／AI 朗读可切换，支持语音缓存、整书与选章后台生成、页面同步和媒体控制。
- 逐书选择 WebDAV 备份，支持分块续传、多本并行上传、可选自动备份和手动还原。

详细介绍见 [软件说明](E阅软件说明.md)，当前更新见 [更新日志](CHANGELOG.md)。

## 使用

从 [GitHub Releases](https://github.com/byonesheart/ERead/releases) 下载 APK。当前版本为 1.9.0（versionCode 29），本地构建产物为 `artifacts/ERead-1.9.0-debug.apk`，与此前本机调试签名一致，可覆盖安装；构建及校验信息见 [验证记录](docs/verification.md)。首次进入需阅读并同意 [隐私政策](docs/privacy-policy.md) 和 [用户协议](docs/user-agreement.md)。未捕获的 Java/Kotlin 异常会在本地保存，下次打开显示“上次异常退出”，可复制日志提供给开发者。首次启动提供一部六章原创示例小说与一部三页原创示例漫画，均标注为“示例”；不会预填阅读历史或进度。

## 界面与导入

- 顶部切换 **小说 / 漫画**，右侧依次为夜间模式、书签与笔记、“＋”导入；底部切换 **阅读 / 书架 / 设置**。阅读首页直接显示书籍、进度和历史，书架从搜索栏开始。
- **阅读**：查看历史并继续上次的阅读位置。
- **书架**：导入本地文件、搜索书名或作者、查看封面/作者/章节和百分比进度/最后一章，切换网格或列表。小说和漫画分别管理自定义分组，支持新建、重命名、删除及从书籍菜单移动到分组；删除分组后书籍回到“未分组”，保留书籍、进度和标注。
- **设置**：仅保留全局夜间、WebDAV 备份、朗读引擎和书库维护，移除顶部模式栏和标语。阅读字体、间距、翻页等在阅读页内分别保存小说/漫画偏好；目录规则位于小说目录右上角。
- 在文件管理器中选择 EPUB、TXT、MOBI、PDF 或图片的“打开方式 → E阅”，应用会加入书架并直接打开；也接受这些格式的分享请求。文件管理器应提供正确的 MIME 类型或带扩展名的文件 URI。

## 文件与目录

| 文件 | 行为 |
| --- | --- |
| EPUB | 按 OPF spine 阅读顺序读取章节，识别 nav/NCX 目录与同一 XHTML 内的多个目录锚点；有正文归为小说，仅有图片归为漫画并使用第一页封面。 |
| TXT | 支持 UTF-8、UTF-16 与 GB18030，按默认或自定义目录规则分章。 |
| MOBI | 支持未加密 MOBI，提取书名、作者，优先使用 INDX / TAGX / CTOC 内置目录，缺失或无效时回退 HTML 章节；有正文归为小说，仅有图片归为漫画，按原顺序保留重复页，第一页作封面。支持未压缩、PalmDOC 和 HUFF/CDIC；混合 MOBI/KF8 读取兼容 MOBI 正文。纯 KF8/AZW3 需转换为 EPUB。 |
| PDF | 系统 PdfRenderer 保留原始排版。单独导入时检查文字层，有正文归为小说供搜索/朗读，无正文归为漫画并使用文件名与第一页封面。漫画文件夹内的 PDF 始终按漫画章节处理，不提取元数据或正文。 |
| 图片 | 支持 Android 系统可解码的图片；多选图片自然排序并合为一本。 |
| 漫画文件夹 | 根目录多分支的子文件夹/PDF 作为章节；章内多分支作为可跳转的小节，可继续嵌套。任意层只有一个可读子文件夹/PDF 时递归合入父级，忽略空目录。散图先读，分支按名称自然排序，书名保留根目录名，第一页作封面，不提取正文或作者元数据。 |

作者仅取自文件元数据或 TXT 明确的“作者：” / “Author:”字段，没有就留空。“最新章节”指当前导入文件的最后一章。文件使用 Android 系统选择器导入，优先保留读取授权并直接引用原文件；可读的本地路径也直接引用，不需要申请全盘存储权限。漫画文件夹的图片与 PDF 不再整批复制。

Android 的系统选择器通常返回文件 URI，应用按 [持久文件授权](https://developer.android.com/training/data-storage/shared/documents-files#persist-permissions) 读取，避免将它强行转换为不可访问的文件路径。无法获得持久授权的临时分享 PDF/图片会保存副本，并显示提示；临时分享的小说仅保存解析结果，授权失效后重新解析需再次选择源文件。EPUB / MOBI 仍保存解析后的文字和内嵌图片，TXT 保存章节文字，另外保存小封面、PDF 文字层与分页缓存；因此减少原文件副本，不代表完全不占额外空间。需要临时文件进行随机读取时，操作完成后删除临时文件。

书籍信息显示“引用原文件”或“应用内保存”。引用的源文件移动、删除或授权失效时，应用显示读取提示；移出书架仅清理应用数据，原文件保留。旧版本未记录外部原文件地址的书籍继续保留已有副本。

“导入文件”统一选择小说或漫画文件，按文件内容分类；“导入漫画文件夹”保留系统目录选择器。若文件管理器在文件入口返回目录，应用也会将它识别为漫画文件夹并导入。

导入时在书架首项显示待加载卡片，封面为圆形进度条，旁边显示当前阶段、文件/章节及阶段百分比；不再弹出整理对话框，可以继续切换页面和模式。扫描等数量未知阶段显示动态圆环。一个导入任务显示一张卡片：单个文件显示文件名，多选显示“导入 N 个文件”，完成后替换为实际书籍，失败后移除卡片并提示。占位不计入分组或已读数量，也不能打开；搜索、分组、在读/读完筛选不会隐藏它。翻页模式下，TXT / EPUB / MOBI 只按当前字体和阅读视口预排版当前章节并写入缓存，期间不显示重复书籍；滚动模式不计算全书页表。

1.7.1 先读取当前章节，再预读后两章与前一章。翻页模式先显示本章页数，全书总页数在后台补齐；改变字号、字体或间距时先处理当前章。每章保存最多三套排版缓存，再次打开或恢复相同设置时可复用。新 EPUB 和默认多章节 MOBI 的特殊段落格式按需准备并持久保存，正文字符与图片位置保持不变；已有书籍使用现有正文缓存。MOBI 首次导入仍需要解压和提取文字，单章无内置目录或自定义 MOBI 目录仍进行完整转换；未缓存的远处章节和特别长的单章可能需要等待。系统清除缓存后需重新计算。

MOBI 目录的锚点和 filepos 采用一次索引，避免每个目录项重复扫描整本书或重新解码正文前缀。普通 EPUB / MOBI 段落去掉解析器自动添加的空行，标题、引用等特殊段落保留格式。旧版内容可从已有正文缓存修正段距并迁移图片、阅读位置和标注。

MOBI 自带目录有效时直接按内置正文位置分章，跳过 HTML 链接及标题推断；二进制目录损坏时安全回退，脚注排除仍生效。正文空白转换仅保存图片和特殊格式边界的位置映射，无标记的章节不再按字符分配映射数组；1000 万 UTF-16 字符可避免该步骤额外分配约 40 MB。旧 MOBI 在源文件可读取时更新一次内置目录并迁移进度与标注，已更新的缓存不重复解析；EPUB 不因 MOBI 内置目录更新而重新解析，普通段落的格式与显示间距见下文。APK 对比与优化依据见 [Neat Reader 分析记录](docs/neat-reader-analysis.md)。

目录识别排除脚注引用、明确标记的注释区域和 HTML 注释中的隐藏标题，注释文字仍留在正文。旧版 EPUB / MOBI 在原文件可读取时自动重建一次目录并迁移阅读位置、书签和笔记；升级成功后不重复解析。原文件不可读取时保留旧书并提示，已有旧版缓存仍可修正段距，但不会把尚未修正的目录标为已升级。

小说目录右上角“规则”可保存多条有名称的正则表达式，通过单选按钮只启用一条，旧自定义规则自动迁移为选中的预设。默认规则保留；修改或切换正在使用的规则时重新生成 TXT / MOBI 目录并迁移阅读位置与标注，保存未启用的规则不重新解析。EPUB 使用自带目录，MOBI 优先使用有效的内置目录。默认规则按整行识别有长度上限的中文“第…章/节/卷/回”等、“Chapter 1”“Chapter IV”“Part 2”“序章”“前言”“楔子”“尾声”“后记”等，不把裸数字或括号注释编号作为标题。

EPUB / MOBI 导入检查解析正文，有文字归为小说；仅有图片时按阅读顺序生成漫画页面，使用漫画的独立阅读设置，不进行文字预排版或目录规则重建。从文件管理器打开时也保留自动分类结果。已有无正文、图片完整的 EPUB / MOBI 缓存直接归入漫画，无需重读原文件；保留进度和笔记，移出不适用的小说分组。既没有正文也没有正文引用图片的文件拒绝导入。TXT 支持长按选区“编辑”替换文字，也可从顶部编辑按钮修改当前章节；修改保存在应用内版本，原文件保留，目录、阅读锚点和标注同步迁移，云端上传使用修改后的内容。

## 阅读操作

TXT / EPUB / MOBI 小说均可长按选区编辑或点击顶部编辑当前章。TXT 继续保存应用内版本；EPUB / MOBI 保存会直接覆盖原文件，并更新阅读器正文、进度与标注。缺少写权限时，系统选择器要求重新选择同一本原文件；内容校验不符不会写入。EPUB 保留 ZIP 内其他资源与格式，MOBI 重建正文压缩记录及标准目录和 filepos，保留元数据和资源；混合 MOBI/KF8 写回兼容的 MOBI6 正文。先校验临时文件再覆盖，失败恢复原书；恢复异常时保留完整原书副本并显示路径。编辑事务与云端备份共享锁，防止打包到新旧不一致的内容。已编辑 MOBI 改目录时从当前缓存重建。书架批量备份的全选、上传、取消操作行位于批量备份入口下方。

- 单击正文或漫画显示/隐藏上下工具栏；工具栏叠加显示，正文尺寸与分页不变。
- 小说滚动模式抑制文字控件获取焦点时的自动滚动，避免单击正文将文字块或光标拉回屏幕；手动滑动、目录和进度跳转仍可使用，长按选区保留。
- 顶部工具栏：退出、书名、快速添加书签、全局夜间切换、搜索。
- 目录全屏显示，打开时定位在读章节；长目录只渲染可见行，点击章节或漫画小节跳到对应位置，左上返回或系统返回键关闭。
- 底部工具栏：目录、朗读、书签、设置，以及可拖动快速跳转的全书进度条；书签入口同时查看笔记、标记与划线，不再单列笔记按钮。进度条两侧可快速跳转上一章、下一章。进度条跳转后显示返回按钮，标出之前的章节和百分比，箭头朝向原位置；点击返回原文字/图片位置。关闭工具栏时清除按钮和本次返回记录，重新打开不恢复。
- 设置入口打开贴紧阅读页底部、最多半屏的紧凑面板，行距、字间距、字体选择和加粗直接显示，无需展开。背景可导入自己的图片，按小说/漫画分别保存，夜间叠加暗色。背景图保留方向与透明度，缩小到最多 200 万像素；损坏或超过 32 MB 的图片会提示。面板可滚动，点击正文或返回键可收起。
- 字体快捷项为系统、宋体、黑体、加粗、更多；更多弹窗显示等宽与已导入字体，可导入本地 TTF/OTF/TTC 字体。翻页模式按实际屏幕尺寸重新分页。
- 小说上下滚动按原文块懒加载，只对可见内容换行；字体或间距变化不再执行全书分页，阅读位置和源文字格式保留。默认使用上下滚动。
- 左右翻页仍需按屏幕计算页数，导入时预排版并显示进度。最近三套布局保存在缓存中，切回常用字号/字体可复用；新格式或新屏幕尺寸需要重新计算，支持退出阅读。字号/间距滑杆拖动期间只预览，松手后提交一次；亮度实时变化。
- TXT、EPUB、MOBI 均支持小说的上下滚动、左右翻页与上下翻页，章节之间可连贯阅读；小说及漫画可在底部设置直接选择带方向图标的滚动、翻页、上下模式。
- EPUB / MOBI 的标题、引用等特殊段落保留源文件的字号比例、粗斜体、对齐和缩进；字体统一替换为软件所选字体。普通正文按软件的字号、间距和格式显示。源格式同时参与显示与分页计算，并纳入分页缓存签名。
- 长按文字可以使用真实选区与拖柄，再添加笔记、颜色标记或划线；划线支持直线与波浪线。长按正文插图、漫画/PDF 页可添加笔记或颜色标记。编辑使用原文附近的不透明气泡，上方空间不足时放在下方。点击对应文字或图片可查看笔记、标记或划线的日期并删除；二十字以内的笔记在气泡中显示，更长的笔记使用弹窗。点击空白仍控制工具栏，滚动和长按不会误开记录。
- 当前阅读页已有书签时，右上角显示持久的书签标识；即使隐藏工具栏仍可看见。
- 夜间开关同步作用于阅读、书架、设置与弹窗，阅读工具栏的返回、搜索、日夜切换、上一章和下一章图标使用对应前景色；关闭时恢复白天阅读背景。亮度只覆盖当前阅读窗口，不修改手机系统亮度。
- 小说／漫画切换栏右侧的书签与笔记入口可跨书搜索书名、摘录和笔记，点击返回原位置。外部入口和书内列表均提供全部、书签、笔记、标记、划线五项紧凑筛选，窄屏或大字号时横向滚动，不将文字挤成竖排。
- 右下角显示百分比和当前页/总页；文字模式的全书页数在后台逐章统计，完成前显示本章页数与统计状态，漫画/PDF 按原页显示。滚动模式按文字与图片位置跳转，不将原文块误称为屏幕页。
- “更多设置”包含滚动/翻页、时间、电量、章节名、保持亮屏、音量键翻页和朗读语速。
- 漫画与 PDF 支持双指缩放、双击缩放、章节跳转及同样的进度和标注操作。
- “朗读”为耳机图标，开启后变红，再次点击直接停止。悬浮条仅在上下工具栏打开时显示，提供按段回退/快进、暂停/继续、关闭、0.5–2 倍语速和同步开关；同步启用时变红。默认与阅读页面独立：手动移动时单独询问“从当前页面朗读？”，“确认”从新位置朗读，“返回原位置”将页面跳到正在朗读的位置而不重启语音；停止移动 1 秒后提示消失。启用同步后页面跟随朗读滚动和翻页；手动导航暂时暂停，稳定 1 秒后继续，原朗读节点仍在当前可见段落/页时保留原语音队列和音频位置，移到其他位置才从新页面建立队列。主动暂停后移动不会自动开播，再次继续时按同样规则定位。后台返回或视口重排保持已有语音队列。朗读段落高亮，PDF 文字层按原页坐标叠加高亮；无字级时间戳的在线 API 按真实音频进度估算块内文字位置。

朗读使用 Android 媒体音频焦点，并提供系统播放栏的暂停、继续和停止操作。系统 TTS 和 AI 共用媒体控制及耳机快捷暂停／继续；耳机抬键、长按重复和重复路由不会再次切换。暂停保留前台媒体卡片并释放焦点；停止立即撤销会话和通知。其他媒体占用焦点时暂停并让出媒体键，普通通知请求临时降低音量时继续朗读。系统 TTS 改变语速时从原文锚点重新启动句段，AI 使用音频播放速度。实现遵循 [Android 音频焦点](https://developer.android.com/media/optimize/audio-focus) 和 [媒体会话回调](https://developer.android.com/media/legacy/audio/mediasession)；实际设备与耳机的响应仍需手机验证。

共用设置的“朗读引擎”子页中点击“当前使用：”右侧按钮切换系统／AI 语音，AI 选中后右侧齿轮编辑配置。朗读悬浮栏右侧齿轮也可打开相同的引擎与配置设置。可命名保存多套配置、选择当前配置或新建；凭据使用 Android Keystore 加密，同配置、同源服务器与同 API 前缀时允许留空沿用密钥，包括 OpenAI／MiMo 两种接口之间切换；更换服务器、HTTP/HTTPS、端口或 API 前缀不会继承密钥。密钥不进入书籍备份。服务器可填 `/v1` 基础地址或完整接口地址，基础地址自动补齐接口路径。

AI 配置内的“测试连接”直接使用当前填写内容合成短句，成功后显示耗时与音频大小，不保存或切换配置，也不写入书籍缓存。改动表单或关闭弹窗会取消测试；401/403 等错误显示有限且脱敏的服务详情。官方 MiMo 未保存密钥时会明确要求填写；如果旧版本已经丢失了密钥，需要重新填写一次。连接测试与正式朗读共用协议、鉴权和音频解码路径。

协议可选 OpenAI 兼容的 [audio/speech](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)（声音 ID、可选 `instructions`，返回 MP3），或 [MiMo chat/completions](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)（`assistant` 正文、`user` 风格、JSON/Base64 WAV）。`mimo-v2.5-tts-voicedesign` 隐藏声音 ID，必须填写音色描述与朗读风格；关闭 `optimize_text_preview` 以保持原文。需要音频样本的 voiceclone 模型暂不支持。正文会发送至用户配置的服务，系统 TTS 的语音包由 Android 系统管理。

AI 音频按书独立缓存在应用内存储，播放当前段落块时预加载后续两块，接近章末时跨到下一章开头，相同的在途文字块共用请求；相同正文、服务、协议、模型和音色参数复用缓存，调整播放语速不重新合成。缓存不随云端书籍备份上传；小说右上角三个点的“清理 AI 语音缓存”单独确认清理，漫画隐藏此项；移出书架也会清理该书音频。清理期间已在生成的旧请求不会重新写回，播放失败的缓存条目会移除，普通暂停／停止保留正常缓存。

PDF 和图片保留原始页面，字号/字体设置作用于 TXT、EPUB、MOBI 小说。漫画文件夹内的 PDF 不提取文字层；单独导入的扫描 PDF 与图片也需先识别文字才能朗读。当前版本不包含 OCR、DRM 解密或在线追更。

旧版已导入的 EPUB / MOBI 在升级后自动补充正文图片和源格式，并迁移阅读位置与标注，无需删除重导。书架封面使用小尺寸缩略图，长图读取限制解码尺寸与像素数量；PDF 导入使用磁盘临时文件，减少漫画文件夹导入的内存占用。

1.6.1 在真正段落之间显示约 0.4 个字号的额外间隔，原有空行或仅含空白的段落不再叠加间隔；滚动文字块只有结束于真实段尾时加入同样的间隔。原文、选区、复制、笔记和 UTF-16 阅读位置保持不变，标题与引用继续保留相对格式。MOBI 内容缓存版本仍为 7，EPUB 仍为 6，本次显示修正不重新解析书籍；分页布局规则更新，旧页表需重新计算一次。

1.6.2 将上述段距加倍至 0.8 个字号；20sp 字号下额外间隔为 16sp。原文与阅读位置不变，翻页缓存算法升至 8，按新段距计算一次页表。

## WebDAV 备份与还原

点击设置中的“WebDAV 网盘配置”，填写服务器完整路径、账户和密码，保留“测试连接”。软件在服务器路径下的 `ERead/` 子目录保存备份，支持 HTTP/HTTPS；旧坚果云账号和上传断点自动迁移，默认服务器为 `https://dav.jianguoyun.com/dav/`。坚果云需使用第三方应用密码，操作见 [官方说明](https://help.jianguoyun.com/?p=2064)。切换服务器或账户后重新选择要上传的书籍，不自动向新网盘上传原网盘选中的书；不同网盘的历史、封面与断点分别保存。

- 点击书籍封面的云图标，首次手动上传该书的内容和记录；上传成功后，该书才加入自动备份范围。小说和漫画共用备份账号。
- 全局“自动备份”默认关闭，开启后仅备份已上传的本地书籍。默认要求系统判定为非计费网络，可打开“允许计费网络自动备份”。后台任务由 Android 调度，不承诺即时上传。书架“批量备份”支持勾选多本本地书籍，分别排队上传；云端占位书先手动下载。
- 备份包含源文件、解析后的正文与插图、源文字格式、书签/笔记/颜色标记、阅读进度、分组、每书角色音色资料、对应小说或漫画模式的阅读设置及字体、累计阅读时长。账号、应用密码及 AI API 密钥不进入书籍备份；本机保存的凭据使用 Android Keystore 加密。
- 仅阅读记录发生变化时复用已上传的正文归档，更新云端记录；应用仍会读取本地备份文件计算摘要。
- 同一本已登记书籍更新记录时，不再查询或改写公共书籍索引的 ETag。新增书籍先检查索引版本，兼容坚果云安全的无引号 ETag；弱版本标记不会被改成强版本以覆盖其他设备的数据。
- 手动上传由持久 WorkManager 任务执行，允许任何已连接网络，使用 dataSync 前台服务；封面进度在重新打开应用后恢复。批量任务按书籍独立保存，网络操作串行，取消一本不取消其他书。自动备份的网络限制由共用设置决定。
- 新内容按 1 MiB 分块上传，归档与已确认块保存在应用私有目录。网络中断后有限重试并继续未确认块；源内容变化会重新生成归档，完整提交成功后清理暂存。1.6.2 已保存的 4 MiB 断点继续按原边界恢复，读取也兼容旧 128 MiB 分块；未保存断点的旧版半成品不能直接续传。
- 当前上传封面的圆环中心显示单个“×”，点击取消准备、排队、上传或等待重试的任务，保留已确认块与以前的云端备份。取消后本机暂停这本书的自动补传，再次手动上传成功后恢复；下载和删除等进度不显示取消上传按钮。阅读首页、历史和书架两种布局均使用同一入口。
- 已开启云端上传的书籍，在右上角“三个点 → 删除云端文件”确认删除。操作删除当前账号该书的云端目录（含历史归档和未完成块）并更新索引，成功后关闭本书自动备份并清除旧上传历史；本地正文、进度与笔记保留。尚未下载正文的云端占位书会连同关联记录移出书架，确认框会说明这一点。
- 还原时先在设置中点击“手动还原书籍信息”，恢复书架信息、分组和记录，保留已有的本地书籍。这一步不下载正文，也不立即更改全局阅读设置。
- 再点击待下载书籍封面的云图标，逐本下载内容。下载会应用该书备份中的对应模式偏好和字体，另一模式的设置及当前全局夜间开关保留。
- 同名书籍先比较稳定 ID、原文件 SHA-256 和正文/漫画页内容摘要。确认同内容时自动保留本地书及其记录，确认不同内容时保留两本；这些自动分支不改网盘。证据不足时列出全部同名本地候选和云端书，可勾选保留一本或多本，至少保留一本；其他同名组中明确保留的本地书不会被误删。只保留一本时按选择更新备份、移除舍弃项；保留多本不主动执行云端去重。需要更新备份时检查计费网络，并要求确认，上传期间也检查网络是否切换。清理被舍弃书籍的应用缓存前先停止其 AI 转化任务，外部源文件保留。旧备份可使用原文件摘要，缺少可用证据时仍询问。
- “批量备份”入口位于全部/在读/读完右侧，进入后勾选需要上传的书籍。

可选云备份及 AI 语音使用 OkHttp 连接用户配置的服务器，禁止携带凭据跟随重定向。应用声明 `INTERNET` 和 `ACCESS_NETWORK_STATE` 权限；本地阅读、文件导入和系统 TTS 无需云账号。

## 1.7.9 同步朗读修复

滚动位置按当前可见项的固定章节/正文块标识定位，避免后台准备前面章节改变列表序号后认错章节；列表重新布局后补发位置更新。启动朗读读取可见起点。同步模式下，暂停后手动翻页、滚动或跳章，再从悬浮条、系统播放栏或耳机继续，会从当前页面建立语音队列；暂停且未移动时继续原语音位置，关闭同步时仍可独立浏览。暂停期间移动页面不会自行开始朗读。

MiMo 对空响应或缺少音频数据的成功响应延迟 300ms 后原段重试一次，连续失败明确提示已重试；鉴权、参数、内容拒绝、未完成生成与格式错误分别处理，不自动跳过正文。重试可取消，失败临时音频删除。额外请求可能产生一次生成用量；未使用真实 API 发起收费测试。

## 1.8.0 语音批量缓存与阅读信息

目录规则默认只显示名称，点击规则或新增后才展开编辑。书籍信息异步显示总字数，按 Unicode 字符统计并排除空白和图片占位符，未下载正文提示下载后统计。

AI 语音生成失败后使用相同文本最多重试三次（首次加重试共四次），包含拒绝、网络、鉴权、空音频与格式错误，取消不重试。朗读设置新增默认关闭的“失败时使用系统语音”：开启后当前失败块由系统语音替代，然后恢复后续 AI 朗读；关闭时显示失败弹窗。系统语音替代保留高亮、暂停、恢复及语速控制，不写入 AI 缓存。接口配置缺失或本地密钥缺失仍先提示补齐。

本地小说更多菜单新增“转化 AI 语音”，可生成整书缓存；目录耳机入口可勾选章节、全选或取消选择。按段落和章节分批提交，复用已完成的每书缓存，不将整本书放进单次 API 请求。底部进度显示章节与音频段完成比例，可中断；保留已完成缓存，删除未完成临时文件。重新启动任务会复用已有结果。批量转换失败后停止并保留进度，系统语音替代仅用于即时朗读。生成使用任务启动时所选 AI 配置，调用及重试产生相应接口用量。当前任务随应用进程运行，中断后可再次启动复用缓存。

AI 翻页朗读按完整章节生成稳定音频块，因此分页和字体变化不使整书缓存失效；系统朗读仍保留按页分段以支持没有逐字位置回调的系统引擎。从段落中间启动时首段可能需重新生成，之后完整段落与章节复用缓存。

滚动阅读右下角按当前字体和屏幕显示“当前页 / 总页数”。总页数后台逐章统计并复用翻页缓存；尚未完成时显示本章页数和统计状态，不阻塞正文。字体、段距和屏幕尺寸变化后重新统计，滚动正文仍保留原有文字块与位置。清理缓存或移出书籍会先停止对应批量任务，避免已清理缓存被该任务重新写回。

## 1.8.3 清理、角色语音与同步续读

整书和选章 AI 转化由持久后台任务执行，可切换其他页面或应用，不显示前台进度窗口；同书最多同时处理三章，批量生成在整个应用内最多同时发出三个语音请求。通知和目录均可中止本书转化，目录按章显示并行进度与等待状态。完成的章节显示耳机内“√”，全书当前音色缓存齐全时整书入口也显示“√”；切换配置后，已验证完整的旧音色缓存以“其他配置”耳机标识保留，不误标为当前配置完成。部分缓存不标为完成，配置、正文或角色资料变化后重新核对。选择、完成数量均以章节为单位，章内请求仍分块以兼容语音 API。完整章节跳过；仅缓存部分段落时重新生成整章，每段新音频成功后原子覆盖旧缓存，生成失败或中断不先删除原音频。系统重新调度使用相同判断；即时朗读继续按段命中缓存。书籍信息显示各配置 AI 缓存总空间，清理或章节完成后刷新。编辑正文、重建目录、清理或删除本书会先停止对应转化，持久计划也校验正文版本、语音配置与角色资料。

后台任务遵循系统调度和省电限制；强制停止应用后需重新打开，系统允许重新调度后续跑。Android 15 的 dataSync 前台服务有累计时长限制，Android 16 长任务也有作业配额，见 [长时间 Worker](https://developer.android.com/develop/background-work/background-tasks/persistent/how-to/long-running) 与 [前台服务超时](https://developer.android.com/develop/background-work/services/fgs/timeout)。设备通知权限未开启时可在目录查看章节进度，系统任务管理界面也受设备版本影响。

在“朗读引擎”设置中管理通用角色及每书角色，五项内容为名字、名字正则、音色、角色描述、角色场景，每个角色五项合计最多 3000 个 Unicode 字符；类别可选角色或旁白，每项可独立启停。默认提供“男人”“女人”两个启用的通用旁白。角色提示词是 AI 配置中默认关闭的试验选项，关闭时不加入这些资料。长按选择正文后可先修改选中文字，再加入新角色或已有角色；加入已有角色的别名只扩充名字正则，重复名字会提示，原显示名字与音色资料保留；描述和场景追加到对应字段。弹窗正文独立滚动，保存、返回等操作固定在底部，窄屏可整齐换行。

启用试验选项后，每个语音请求最多使用一种角色音色，优先级为本书角色、本书旁白、通用角色、通用旁白。按完整段落的名字正则和引号前后“说/问/答/道”等表达判断说话者；同段多角色无法唯一确定时按句处理，未署名的对话可沿用前句、前段及上一章的对话角色。没有角色或对话线索时，从最高可用层级的启用旁白中选择一个；该选择以书籍、章节/页和段落位置作稳定伪随机，同一段反复打开或转化不会随意换音色，无可用旁白则不添加角色提示。即时朗读、批量转化与缓存核验共用相同计划，OpenAI 与 MiMo 均使用提示词传递资料，实际正文不混入说明。从段中启动保留前文上下文，仍从所选位置朗读；并行章节预先确定对话继承关系。每书角色作为书籍元数据随 WebDAV 备份，不包含 API 密钥；修改资料会改变相关语音缓存键，旧音频不先删除。

“清理缓存”分别显示阅读历史、AI 语音缓存、阅读笔记和角色信息的本地占用。历史、笔记和角色按相应 UTF-8 元数据统计，AI 音频按实际磁盘文件统计；元数据大小不承诺等量释放文件系统空间。清历史保留阅读进度；清笔记同时清除颜色标记与划线，保留书签；清角色包含通用及每书角色；AI 音频仅在本机保存。确认框可勾选同时清空云端对应记录，保留云端正文归档；计费网络需额外确认。未勾选时仅处理本地，本次不触发自动备份立即覆盖云端，后续手动或自动备份仍按本地最新状态更新。AI 音频没有云端副本，勾选也不删除云端书籍。移出书架的确认框同样显示本地占用和云端选项，统计不计入外部源文件，取消不执行删除。

书内的应用级操作提示缩短为 1 秒；书签、笔记、标记和划线统一从紧凑筛选查看。同步朗读手动调整后优先恢复仍可见的原节点，避免小幅移动或返回原段时重读；跳到其他页面才建立新队列，主动暂停后不会因移动自动播放。

阅读“更多设置”可恢复当前小说或漫画模式默认偏好，保留导入字体、已存目录规则及全局外观选择。底部直接显示带方向图标的滚动、翻页、上下模式，字体快捷项为系统/宋体/黑体/加粗/更多。划线样式使用直线与波浪图案，选区菜单和气泡根据实际选项宽度收紧，窄屏继续通过竖三点展开多余项目。

全文搜索与替换支持 TXT、EPUB、MOBI 的单个匹配替换、编辑或整书全部替换。忽略大小写、按普通文字非重叠匹配，替换为空表示删除；匹配始终基于原文，不会递归替换新插入的字。最多展示前 100 个结果，整书替换覆盖全部匹配并在执行前确认。单处替换先复核原文，保存后恢复搜索面板与替换内容。TXT 更新应用内文本和目录，EPUB/MOBI 使用既有原文件写回事务，校验后覆盖并同步迁移阅读位置、笔记、标记、图片与格式位置；权限不足时重新授予同一源文件写权限，再继续替换。PDF、漫画及未下载书籍保留搜索入口，不提供文本替换。

AI 语音配置的测试中、成功或失败反馈固定在弹窗标题下方，滚动表单后仍可见；失败显示脱敏原因，修改参数或关闭弹窗会取消过期请求。
